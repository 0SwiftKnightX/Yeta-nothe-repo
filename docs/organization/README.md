## Status vocabulary

- **IMPLEMENTED** — exists and acceptance evidence is recorded.
- **PARTIAL** — some defined scope exists; gaps are listed.
- **MISSING** — inspection confirms the scoped artifact/capability is absent.
- **UNKNOWN** — not inspected or evidence is insufficient.
- **BROKEN** — a reproducible test fails.
- **DUPLICATED** — overlapping implementations are confirmed.
- **PLANNED** — intended, not implemented.
- **DRAFT** — text is proposed and not yet approved.
